# IN-Zukunft Website

Statische Website des IN-Zukunft Nachhaltigkeitsnetzwerks Ingolstadt, ausgeliefert über GitHub Pages unter https://in-zukunft.net.

Alles steckt in `index.html` (Inhalt, Styles, Skript, Logo als SVG). Impressum und Datenschutz sind Ansichten derselben Seite (`#impressum`, `#datenschutz`).
